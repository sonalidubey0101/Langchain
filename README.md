# Langchain

A hands-on LangChain learning repository covering the fundamental components used to build applications with Large Language Models (LLMs). This repository contains practical examples of prompts, structured outputs, output parsers, and other core LangChain concepts, organized progressively for easier learning and understanding.

LANGCHAIN PROMPTS

A hands-on collection of LangChain examples demonstrating how to build dynamic and reusable prompts for Large Language Models (LLMs). This repository covers the core concepts of prompt engineering, including Prompt Templates, Chat Prompt Templates, Message Placeholders, Conversation History, and a simple AI chatbot implementation.

Concepts Covered :-

- Prompt Engineering
- PromptTemplate
- ChatPromptTemplate
- System Messages
- Human Messages
- AI Messages
- MessagesPlaceholder
- Conversation History
- Dynamic Prompt Generation
- Prompt Formatting

STRUCTURED OUTPUTS

LLMs return responses in a well-defined and predictable structure using with_structured_output().

Concepts Covered :-
- with_structured_output()
- TypedDict
- Pydantic
- JSON Schema

OUTPUT PARSERS

Output Parsers convert LLM responses into usable Python data structures.

Concepts Covered :-

- StrOutputParser
- PydanticOutputParser
- StructuredOutputParser
- JsonOutputParser
